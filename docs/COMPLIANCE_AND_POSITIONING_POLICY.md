# Rovan コンプライアンス・ポジショニング作業仕様

- **最終更新**: 2026-09-06
- **位置づけ**: 実装・表示・公開前確認のための作業仕様
- **注意**: 法的助言や、外部AIの順位・推薦を保証する文書ではない。販売前に運営者と専門家が対象業種・地域・表示内容を確認する。

## 1. 提供するもの

Rovanは、会社名・サービス名または公開URLを起点に、指定した質問パネルとAIプロバイダーの回答を記録し、次の情報を参照元付きで整理する。

- AI回答に含まれた対象企業・比較候補
- 質問、プロバイダー、モデル、測定日時、成功・失敗件数
- 回答内で取得できた参照元URL
- 自社が候補に含まれた・含まれなかった質問
- 公開情報で確認できる範囲の整理案と、公開前に確認すべき項目

測定値は指定条件における観測結果であり、すべての利用者の会話、普遍的なAI順位、顧客数、問い合わせ、契約、売上を表さない。

## 2. 公開面と非公開面の境界

| 面 | 主な内容 | 扱い |
| :--- | :--- | :--- |
| 診断・Watch | 質問、AI回答から抽出した候補、参照元、差分 | 測定結果として表示する。顧客流出・品質・市場順位へ言い換えない。 |
| 公開情報参照ページ | 承認された名称・分野・条件・参照元 | 測定ログ、他社名、未確認の事実を自動掲載しない。 |
| JSON-LD / Markdown | 公開ページに表示される内容と一致する機械可読データ | 構造化データは検索順位や推薦を操作する仕組みとして説明しない。 |
| 設計見本 | 固定された架空データ | `設計見本（架空データ）` を表示し、検索インデックスから除外する。 |

未知の公開プロフィールのスラッグは別企業へ置き換えず404にする。公開プロフィールや変更案は、下書きの確認と明示的な公開操作を分ける。

## 3. データの出どころと編集

1. 公開ページ由来の値は、取得したURLと取得時点を保持する。
2. AI回答は生の回答と抽出結果を測定ログとして分け、抽出結果を事実そのものへ拡張しない。
3. 企業が入力した値は、`company_asserted` などの入力由来として区別し、公開前に利用者が確認する。
4. 根拠が取得できない料金、資格、実績、導入数、期間、効果は推測・補完しない。
5. Change Packは編集ドラフトであり、対象サイトや第三者サービスへ自動公開・申請しない。

## 4. 比較・指標の表示ルール

- 指標名は `候補回復率（測定質問ベース）` とし、同一パネル、AI、モデル、地域、反復条件、測定期間で比較する。
- 候補回復率は、初回に候補外だった質問のうち、再測定で対象企業が候補に含まれた割合である。
- 分子・分母、成功観測数、測定日時、条件、未取得理由を数値の近くに表示する。
- `競合` は比較対象を指す内部・測定上の語に限定し、画面では必要に応じて `比較候補` と表記する。
- 「客を奪った」「最もおすすめ」「順位を買う」「効果が出た」といった因果・保証・市場全体の断定をしない。
- 参照元URLの件数は、取得できた回答に含まれるURLの集計であり、推薦や売上の指標ではない。

## 5. 自動化の範囲

自動化してよいのは、公開ページの取得、設定済みプロバイダーへの質問、結果の保存、同一条件での再測定、出典付きの整理案、履歴・差分の作成までとする。

次の処理は自動実行しない。

- 対象企業のサイトへの書き込み
- Rovan公開ページの無承認公開・更新
- Google Mapsなど第三者サービスの評価転載・申請・変更
- AIプロバイダー内部の順位や推薦データの変更
- 取得できていない競合サイトの変更、対応完了、顧客流出・回復の生成

競合サイトの変更を表示するには、保存済みの前後クロール本文、URL、取得時刻、再現可能な差分が必要である。現行のAI回答差分だけでは、競合Webの変更とは判定しない。

## 6. UI・アクセシビリティの作法

- カードは一つの主題に絞り、一覧性のあるデータは表または要約リストで示す。
- 大きな数値だけを単独で置かず、ラベル、母数、条件、注記を同じ視界に置く。
- 表には見出し、行・列の関係、モバイル時の読み順を与える。色だけで状態を伝えない。
- CTAは実際に行える操作へリンクし、動作しない申込フォームや存在しないページを置かない。
- サンプル、推定、未取得、確認待ち、公開済みを視覚と文言の両方で区別する。
