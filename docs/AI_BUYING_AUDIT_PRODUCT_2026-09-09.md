# Rovan AI購買監査 — 2026-09-09 方針

## 結論

Rovanは「LLMOスコアを見るツール」ではなく、**AIが購買前の利用者に対して対象企業をどう選び、どう説明しているかを継続監視するサービス**として扱う。

ユーザーが受け取る価値は次の3点。

1. **候補落ちの発見** — 購入に近い質問で、自社が候補外になり競合が候補に入っている場面を見つける。
2. **AI誤情報の発見** — 料金、利用条件、機能、連携、無料体験、対応地域など、AI回答と公式サイトに明確な矛盾がある場合だけ検出する。
3. **変化の監視** — 前回は候補入りだった質問の候補落ち、新しい競合、新しい誤情報、外部参照元の変化をWatchで記録し、重要な変化だけ通知する。

## 既存機能の扱い

### 中核として残す

- URL / 社名からの会社・市場・競合理解
- Buyer Prompt生成
- OpenAI / Gemini / Perplexityの統一条件観測
- 候補入り、第一候補、競合、Citation
- Evidence Gap
- Change Pack
- Watchと前後比較
- Stripe課金

### 主役から外す

- Rovan公開会社ページ
- `llms.txt`
- JSON-LD

これらは補助機能・検証対象として残す。公開ページを作ればAI推薦が改善すると断定しない。

### 今は必須にしない

- GitHub接続
- WordPress管理者権限
- FTP
- 顧客CMSへの自動書き込み

導入摩擦を上げるため、初期商品には要求しない。

## AI購買監査の実装契約

### 商用意図の優先

全質問を同じ重さで扱わない。比較、価格、代替、機能、用途、対象顧客など購入判断に近い質問を優先し、最大12問を購買監査の主対象にする。

これは検索ボリューム、購入確率、売上予測ではなく、Rovan内部の相対優先度である。

### 候補落ち

重要質問ごとに、取得成功した回答で自社が候補に入った割合を計算する。AI別にも候補外が優勢かを見る。

表示例:

- 重要質問: 「中小企業向けで料金を比較したおすすめは？」
- 自社候補入り: 0%
- 候補外が多いAI: OpenAI / Gemini / Perplexity
- 他社候補: A社 / B社

### AI誤情報

誤情報として扱う条件は厳しくする。

- AI回答本文に実際に書かれている短い事実表現がある。
- 対象企業の公式サイト本文にも、その項目について明確な別の事実表現がある。
- 両者が直接矛盾する。

公式サイトに書いていないだけでは誤情報にしない。推測で「正解」を作らない。

対象例:

- price
- eligibility
- capability
- integration
- trial
- region
- support
- security

### Citation依存

重要質問でAIが使った参照元ドメインを、自社と外部に分けて集計する。外部ドメインの存在そのものを危険と断定しない。誤情報と結びついたとき、またはWatchで新しい参照元へ変化したときに確認対象とする。

### Watch異常検知

同じ測定パネルで比較可能な場合、次を異常イベントとして記録する。

- candidate_drop — 前回50%以上候補入り → 今回50%未満
- candidate_recovery — 前回50%未満 → 今回50%以上
- new_competitor — 前回なかった競合候補が新規出現
- citation_change — 重要質問で新しい外部参照元ドメインが出現
- new_fact_error — 前回の事実監査にはなかった明確な事実不一致

比較条件が一致しない場合、候補落ち・新競合・Citation変化を前後差として断定しない。

## Change Pack

Change Packは引き続き使うが、商品の主役ではない。

問題が検出されたときに、対象ページ、見出し、本文、FAQ、根拠、関連質問を人間が確認できる修正案として出す。顧客サイトを無断で変更しない。

## UI

結果画面では、従来のCitation表の前に「AI上の購買監査」を表示する。

最初に見せる数字:

- 重要質問で候補外
- 公式情報との明確な食い違い
- 重要質問で使われた外部情報源

その下に、重要アラート、誤情報の具体例、購入に近い質問の候補入り状況、外部参照元を表示する。

## 通知

Watchで新しい候補落ち、AI誤情報、新しい競合が検出された場合、既存の週次Watch通知に加えて購買監査アラートを送る。

平常時に毎週宿題を出さない。問題がない週は、ユーザーが作業しなくてもよい設計を維持する。

## 料金

Watchの表示価格は検証価格として **月額19,800円（税込）** に変更する。StripeのPrice IDは外部設定なので、マージ・本番公開前に19,800円のPriceと一致することを必ず確認する。

## Truth boundary

- AIの内部ランキングは取得できない。
- 全ユーザーのChatGPT会話を見ているわけではない。
- OpenAI観測はRovanが固定条件で実行するWeb検索付きAPI観測であり、消費者UI全体の順位ではない。
- 候補外は実際の顧客流出を意味しない。
- 前後差だけで施策の因果効果を断定しない。
- 事実誤りは、AI回答原文と公式サイト原文に明確な矛盾が確認できる場合だけ扱う。
