# AIX Next

AIX Next is a clean-room rebuild of an AI buyer-intelligence product for Japanese B2B companies.

The product starts from one question:

> When a buyer asks an AI to compare vendors, where does this company enter—or fall out of—the shortlist, and what verifiable evidence would change that outcome?

This repository is intentionally rebuilt from zero. Product strategy, UX rationale, measurement methodology, data boundaries, and implementation decisions live in `docs/` and are treated as part of the product.
